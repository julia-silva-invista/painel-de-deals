# Painel de Deals — PPA Invista

Painel para centralizar análises de crédito (prévia, recuperação judicial, créditos e ativos imobiliários) a partir de arquivos .docx/.xlsx enviados pelo usuário.

Todo o processamento acontece no navegador — nenhum documento é enviado a este servidor.

A aba de análise por IA requer uma chave de API da Anthropic, inserida pelo próprio usuário na tela de upload.
